# 범용 모델 영상별 인식 확인 페이지

`data/sample_data (번호).mp4`를 현재 범용 사람 검출 모델로 한 편씩 재생하며, 검출 박스를 큰 화면에서 확인하는 독립 페이지입니다. 기존 프론트엔드·백엔드·Jetson 서버와 별도로 동작합니다. 혼잡도, 예측, DB 저장 기능은 포함하지 않습니다.

## 실행

프로젝트 루트에서 다음을 실행합니다.

```powershell
python -m uvicorn model_video_review.app:app --host 127.0.0.1 --port 8770 --workers 1
```

브라우저에서 <http://127.0.0.1:8770/>을 엽니다. 종료할 때는 실행한 터미널에서 `Ctrl+C`를 누릅니다.

실행 환경에 패키지가 없다면 프로젝트의 `backend/requirements.txt`에 정의된 의존성을 먼저 설치해야 합니다. 모델 파일 기본 위치는 `runs/training/lambs_yolov8n_21videos_v1/weights/best.pt`입니다. 다른 범용 모델을 시험할 때만 `SHEPHERD_REVIEW_MODEL` 환경 변수로 모델 경로를 지정합니다.

## 사용법

- 상단 드롭다운에서 영상 번호를 선택하면 곧바로 해당 영상으로 전환됩니다. 다시 보기와 다음 영상 버튼도 사용할 수 있습니다.
- 화면에는 사람 검출 박스와 신뢰도, 현재 검출 인원만 표시합니다. 드롭다운의 `완료` 표시는 현재 브라우저 세션에서 끝까지 재생한 영상에만 붙으며, 검수 결과나 정확도 점수로 저장되지는 않습니다.
- 기본 추론 설정은 입력 크기 640, 신뢰도 0.25, NMS IoU 0.45, 사람 클래스만 검출입니다.
- CPU가 원본 영상 프레임 속도를 따라가지 못하면 중간 프레임을 건너뜁니다. 이 페이지는 **육안 확인용**이며 모든 프레임의 정답 검증이나 정량적 정확도 평가를 대신하지 않습니다.

이 페이지는 한 명이 한 영상을 확인하는 용도입니다. 여러 브라우저에서 동시에 재생하면 추론이 직렬화되어 느려질 수 있습니다.
